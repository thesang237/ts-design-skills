A calm system, applied without exceptions.

Everything on this page reads from one tokens file: a 4px spacing scale, a short type scale, warm paper neutrals with one accent, hairline-first surfaces and a single double-ring focus style. Use the switches above to change theme and control height (density), press Tab to see the focus ring, and open the sections to check contrast, every component state, a properly wired form and the two dialects.

02 · contrast

Live contrast checker

Computed from the real token values in the current theme. Text needs 4.5:1; component boundaries, meaningful icons and focus rings need 3:1 (WCAG 2.2). Toggle the theme and watch the results change.

The accent fill is not used as a boundary on its own: an accent button also carries ink text, which is what identifies it.

03 · states

The state matrix

Every interactive component, every state, designed once as tokens. The cells use forced-state classes so you can see them side by side; real hover, focus and press work on the first column too.

Hover is gated by @media (hover: hover) and (pointer: fine). Disabled keeps its shape at 45% and says no. Loading keeps the label and the width. Focus is the same double ring for all of them.

04 · forms

A form that is wired, not painted

Visible labels bound to inputs, hints, aria-invalid and aria-describedby, :user-invalid (errors appear only after interaction), a focus-moving error summary, a growing textarea, and no dead submit button.

We only use it to send the receipt.

⚠Enter an email like name@example.com

At least 8 characters.

⚠Use at least 8 characters, you typed 0.

How should we contact you?

What to look for

  • Click a label: its input focuses. That is the binding doing its job.
  • Type half an email and Tab away; then try to submit empty. Errors come after interaction, say how to fix it and keep what you typed.
  • Submit with errors: focus moves to the summary, which lists each problem.
  • The submit button is never disabled for a hidden reason. While “saving” it keeps its width.
  • Tab: the double ring is visible on every control, on both themes.

06 · dialects

Same rules, two dialects

The product dialect (left) reflows, shows visible controls and uses a fixed type scale. The showcase dialect (right) scales like one image (here 1em = 1cqw, the in-page version of 1em = 1vw), uses hairlines, empty space and display type, and has no radius or shadow. They share colour roles, spacing discipline, states and focus. Resize the window to see the difference.
